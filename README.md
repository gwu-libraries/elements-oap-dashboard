# Elements-OAP-Dashboard

Dashboard that ingests a CSV that contains at least the following columns:  
- `publication_date`  
- `year` (TODO: de-redundant-ify with the above)
- `author`  
- `open_access_status` with values in `{'Closed Access', 'Open Access', 'Hybrid OA', 'Bronze OA', 'Gold OA', 'Green OA'}`.  

Built in R with Shiny.  More to come.
